# Maana Kiyomizu

Guest guide and companion journey diagram.

- Guide: https://viola-creator.github.io/Kiyomizu/
- Journey: https://viola-creator.github.io/Kiyomizu/journey/

The published guide uses `1234` as a placeholder door code. Wi-Fi credentials are shared separately and are not included in this repository.

Static HTML; no build step is needed. GitHub Pages publishes from the root of the main branch. Edit `index.html` for the guide and `journey/index.html` for the activity diagram.
